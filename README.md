# 🚀 SantiDev Project

### 📌 Descripción del Problema
En el ecosistema tecnológico actual, muchos estudiantes y desarrolladores emergentes carecen de una plataforma integrada y organizada para documentar, estructurar y dar visibilidad a sus proyectos de software de forma modular. **SantiDev Project** nace para resolver esta necesidad, ofreciendo una SPA (Single Page Application) limpia y escalable que sirve como base para centralizar el portafolio de desarrollo, facilitando la navegación rápida, estructurada y profesional de proyectos tecnológicos.

### 🛠️ Tecnologías Utilizadas
* **Frontend Library:** React (v18+)
* **Build Tool / Entorno:** Vite
* **Paquetes & Gestor:** NPM
* **Estilos:** CSS3 nativo (usando arquitectura Flexbox para un diseño responsive y Sticky Footer)

### ⚙️ Instrucciones de Instalación
Si deseas replicar o correr este proyecto localmente:
1. Clonar este repositorio: `git clone <enlace-de-tu-repositorio>`
2. Instalar todas las dependencias necesarias: `npm install`
3. Iniciar el servidor local de desarrollo: `npm run dev`
